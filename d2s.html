How to use this
  1. Pick the check type. “Next morning” checks a day against the following morning’s report (the 24-hour check). “Same day” is a live count of what’s still sitting there now.
  2. Add the dock transaction log (box 1): one file covering several days, or one per day. Repeats are only counted once.
  3. Add the morning inventory reports (box 2): one per morning. The date is read from the file name, like “Inventory Value Report for 2026-10-15”.
  4. Read the result. The big numbers show pallets to put away (opportunities), how many were put away in time, and the dock-to-stock percentage. Click any item to see its pallets.
  5. Mark exceptions for pallets that are allowed to sit, like ones waiting on a vendor: open the item and pick a reason. They count as good in the percentage until they’re put away or the exception ends.
  6. Press Save so the day goes into the daily log. Each saved day’s leftover pallets carry into the next day. At the end of the week, use Download week in the daily log to keep a copy.
  7. Real 24 hours sits beside the report’s number. The morning report only sees the dock at about 3 AM, so pallets put away later that morning look missed. Real 24 hours uses the time each pallet actually left the dock. A day shows Preliminary until the next work day’s transaction history is loaded, then it finishes on its own, even for days already saved.
Opportunities are every pallet that needed putting away that day: the ones carried over from the day before plus the ones received. Date ranges: each day is checked against the next morning’s report (Friday against Monday), and its not-done pallets carry into the next day. The first morning’s report is the starting dock. Carried in pallets come from the day before. When there’s no earlier day, they come from the starting report or are estimated from what was on the dock (marked ≈). Other stock is quantity on the dock that isn’t an opportunity, like pallets staged onto the dock from the warehouse. It isn’t counted. The reports only have quantities, so the tool can’t always tell which pallet of an item is still there. LPNs the log shows fully moving off count as done; of the rest, the oldest pallets are counted as the ones left (marked ≈).
