MFN PDF Renamer

Rename PDFs by MFN number

Renames scanned receiving paperwork to its PO number (the number after MFN-), and splits a big scan into one file per shipment. How it works is at the bottom of the page.

How to use this
  1. Drop in the PDFs (or click the box to pick them). One big scan of the whole stack is fine.
  2. Wait while each page is read. Scanned pages take a few seconds each. The list fills in as it goes.
  3. Check the status of each file. MFN found is done. Check this is a best guess: look at the number and fix it in the box if it's wrong. Needs a number: type the number in.
  4. Files save on their own when a batch finishes: one file as a PDF, several as one zip. Use Download all to save again after fixing numbers.
  5. Pages joined or split wrong? Click Pages on that file and turn New file on or off under any page.
How it reads each file: every page is checked for MFN- and a number, highlighted or not, including scanned pages, which are read from the page image (a few seconds per page). If there's no MFN, it uses a lone 31x PO number (like 3100001) and marks the file for a quick check. If it finds neither, the file is marked Needs a number for you to type in. One PDF with several shipments? Drop it in as-is. A new file starts at every page with the RECEIVED stamp, a marker N or New near the bottom right, or a different MFN. Pages with none of those, like page 2 of a packing slip, stay with the page before them. Split or join by hand: click Pages on any file from a multi-page PDF to see every page and turn New file on or off. No need to upload again. To mark where a new shipment starts: stamp its first page with the RECEIVED stamp, or write a big N near the bottom right corner in marker. It learns: when you fix a number, it remembers where that vendor's form keeps it and looks there first next time.

Pages

Each page with New file turned on starts a new PDF. Turn it on to split a file, or off to join a page onto the file before it.
