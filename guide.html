How it works

A step-by-step guide to every tool in the Warehouse Toolkit, written so someone using it for the first time can follow along. Set up your save folder once, then pick a tool below and follow the numbered steps.

Before you start

  • Everything happens in this page. Files you drop in are read on your computer. Nothing needs installing.
  • Dropping files: drag them from your folder onto the box, or click the box and pick them. Several at once is fine.
  • Reports and files you download go to your Downloads folder, like any other download.
  • First time on a computer: see Set up a folder for your saved work below. In short: click Saving to in the top right. Import the company settings file (sites, addresses, names, part weights), then choose Save to a folder… and pick a folder, for example Documents\Toolkit Data. Edge or Chrome asks to let the site edit files in that folder: allow it.
  • Your saved work (daily log, exceptions, reasons, corrections) is kept in that folder. If you skip the folder it's kept in this browser only, and clearing browsing data erases it.
  • Moving to another computer: Saving to → Download backup, then Restore from backup on the other computer.
  • Each tool also has a short “How to use this” at the bottom of its own tab.
Once per computer · about 2 minutes

Set up a folder for your saved work

The toolkit saves your daily log, exceptions, Dock Priority reasons, the watch list and everything it learns into a folder you pick. Files in a folder are easy to back up, and they don't disappear if someone clears the browser.

Make the folder

  1. Open File Explorer and go to Documents. (Later, when the team shares one, use the shared drive folder instead.)
  2. Right-click an empty spot, choose New → Folder, and name it Toolkit Data.

Point the toolkit at it

  1. Open the toolkit in Edge or Chrome. (Firefox and Safari can't save to a folder.)
  2. Click Saving to: This browser in the top right corner.
  3. If you haven't yet, click Import settings file and pick warehouse-toolkit-settings.json. The page reloads; open Saving to again.
  4. Click Save to a folder…, go to Documents → Toolkit Data, and click Select Folder.
  5. The browser asks to let the site view files, then to save changes in that folder. Allow both. If it offers Allow on every visit, pick that so it doesn't ask again.
  6. If it asks to copy what's already saved in this browser into the folder, click OK so nothing is lost.
  7. The page reloads and the top right says Saving to: 📁 Toolkit Data. You're done.

Good to know

  • A yellow bar says “Reconnect folder”: some browsers ask for one click each visit before they open the folder again. Click Reconnect folder and allow it.
  • Don't move or rename the folder after you've picked it. If you do, open Saving to → Change folder… and pick it again.
  • Sharing with the team later: make one Toolkit Data folder on the shared drive and have everyone pick that same folder. Everyone then sees the same daily log, exceptions and reasons; changes show up within about 30 seconds.
  • New computer: on the old one, Saving to → Download backup. On the new one, set up the folder, then Restore from backup. Or just pick the same shared-drive folder.
  • Don't edit the files inside the folder by hand. The toolkit reads and writes them itself.
