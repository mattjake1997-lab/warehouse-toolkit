How to use this
  1. Each morning, drop in the on-hand by LPN report (box 1). That's what's on the dock right now.
  2. Drop in the transaction history (box 2) so it knows when each pallet was received. Load about two months once, then just the previous work day's file each morning.
  3. Optional: drop in the MFN Inventory Value report (box 3) for dollar values, so high-value parts move up.
  4. Work the list from the top. Red rows have been on the dock over 24 hours. Orange rows are due this shift; each one shows its due time and how many shift hours are left.
  5. Pick a reason for anything that has to sit. Excused reasons drop it to the bottom; everyone using the toolkit sees the reason.
Priority is first in, first out: the oldest received pallet on each part sets its place. Parts worth more than the high-value amount count as one extra work day old, so they move up. Over 24h means more than 24 hours since it was received, with Saturday and Sunday skipped (the same rule as Dock to Stock). Since nobody works overnight, a pallet is due at the same time on the next work day. Due this shift means it has to be put away before this shift ends (or the next one, after hours) to stay under 24 hours. Shift hours left counts only the time inside your shift, set under Settings (7:00 to 4:00 to start). No receipt found means the LPN is on the on-hand report but not in the loaded transaction history. It’s counted from the first day it showed up until a transaction file fills in the real date. Excused parts are ones you mark as OK to sit, like waiting on a vendor. They drop to the bottom and stay there until they’re put away or you change the reason.
