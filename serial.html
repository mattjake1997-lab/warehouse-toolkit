How to use this
  1. Scan the stack into one PDF and drop it in box 1. Scanned pages take a few seconds each to read.
  2. Tell it what the serials look like. Easiest: paste one real serial in the example box and click Make pattern. Check the pattern: the start that's the same on every serial stays as letters; the rest becomes # (number) and @ (letter).
  3. Type how many there should be in Count.
  4. Read the result. Green: found exactly that many. Orange: some are missing or extra. The orange Check tag means a letter and number looked alike (like O and 0) and it guessed. Doubled means the same serial is on more than one page.
  5. Missing some? Look at Close, but not matching and the orange pages with nothing found. Click a page to see it. Add any it missed with Add by hand, and take out wrong ones with ✕.
  6. Copy all serials to paste into Oracle or an email, or Download Excel for a list with the page each serial is on.
