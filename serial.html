How to use this
  1. Scan the stack into one PDF and drop it in box 1. Scanned pages take a few seconds each to read.
  2. Type how the serials start in Starts with: the first few characters every one of them shares, like 5426.
  3. Type how many there should be in Count.
  4. Read the result. Green: found exactly that many. Orange: some are missing; red: extras. Serials read from a barcode are exact. One read only from the printed text gets an orange Check tag, so look at it. Odd length means it's longer or shorter than the rest. Doubled means the same serial is on more than one page.
  5. Missing some? Look at the orange pages with nothing found. Click a page to see it. Add any it missed with Add by hand, and take out wrong ones with ✕.
  6. Copy all serials to paste into Oracle or an email, or Download Excel for a list with the page each serial is on.
