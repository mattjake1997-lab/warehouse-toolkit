How to use this
  1. Drop in the BOLs: PDFs (printed or scanned) or Word files. A scan with many BOLs is split into one row per BOL.
  2. Read the table at the top. For each warehouse: how many times a shipment went there from your main warehouse, and how many times one came back, with the pallets each way.
  3. Check the list. A Check row couldn't be matched to a warehouse: pick Ship from and Ship to. An amber pallet box is a guess or a blank: type the right number from the BOL.
  4. Download PDF report for a one-page summary to send or print.
Warehouses (names, addresses and how they read on a BOL) come from the company settings file imported on the toolkit page. Pallets come from the Grand Total on each BOL. When it can't be read, the skid count under Handling Unit is used and the box is marked amber to check. Box truck: a BOL whose carrier says Box Truck counts as a box truck trip. Add other names your truck goes by in Other box truck names. It learns: when you fix a Ship from, Ship to or carrier, it remembers that spelling and uses it on the next BOLs.
